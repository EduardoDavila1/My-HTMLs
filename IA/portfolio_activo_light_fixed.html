INNOVACIÓN Y AUTOMATIZACIÓN

Integración de IA Generativa

Este proyecto audiovisual fue desarrollado para ACTIVO, una plataforma de software diseñada para la automatización de procesos y la gestión inteligente de mantenimiento empresarial.

Para lograr una estética de vanguardia acorde al perfil tecnológico del cliente, el flujo de trabajo integró IA Generativa mediante modelos de difusión de imagen y video.

La sinergia entre las técnicas de motion graphics tradicionales y la síntesis generada por IA permitió no solo acelerar el proceso creativo, sino alcanzar una gran riqueza visual llena de detalles.
